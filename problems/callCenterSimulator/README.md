# Call Center Simulator Problem 📞

## Description
Its a Simulator of Call Center, where calls are come, process it and also view the queue.

### Rules
1. function to receive the call.
2. each call processing like queue (FIFO).
3. function for receiving, processing and view the queue.
## Example

Calls in queue: 0
1. Receive Call
2. Process Call
3. View Queue
4. Exit
